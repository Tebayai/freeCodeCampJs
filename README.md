## Mon approche

Je préfère essayer de résoudre les exercices par moi-même avant de consulter une solution.

En cas de blocage :

1. Je relis l'énoncé
2. Je cherche à comprendre l'erreur
3. Je consulte la documentation
4. Je cherche des pistes
5. Je corrige ma solution
6. Je note ce que j'ai appris
